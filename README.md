# Müşteri Ayrılma Tahmini (Churn Prediction) - Ara Ödev

**Hazırlayan:** Taha SARIKAYA  
**Proje Amacı:** Bu proje, müşteri verileri üzerinden müşterilerin ayrılıp ayrılmayacağını (churn) tahmin eden uçtan uca temel bir makine öğrenmesi akışını gerçekleştirmektedir.

## Proje Yapısı
- `churn_prediction.py`: Veri işleme, model eğitimi ve değerlendirme adımlarını içeren ana betik.
- `musteri_verisi.csv`: Üretilen sentetik müşteri verisi.
- `requirements.txt`: Gerekli kütüphaneler.
